# API Reference

This document provides API reference information for the CEPC packages.

## Packages

### @cepc/shared-config
Shared scientific model schema for MFM v3.

### @cepc/cpu-reference
TypeScript CPU reference implementation of MFM v3.

### @cepc/webgpu-core
WebGPU compute foundations.

### @cepc/webgpu-mfm
WebGPU implementation of MFM v3.

### @cepc/experiment-api
Experiment orchestration layer.

### @cepc/react-ui
React UI for real-time visualization.

## API Stability

APIs are subject to change as the project evolves. We follow semantic versioning where possible, but breaking changes may occur in early versions as we refine the implementation.

For the most stable APIs, refer to the shared-config package which defines the MFM v3 schema.
